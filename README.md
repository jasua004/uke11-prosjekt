kort plattformer laget i godot 4.6. samle 6 mynter og kom deg til slutten

# how to play
**du må ha python og flask installert.**
kjør app.py og klikk på lenken konsollen gir deg.

# controls
WASD, arrow keys

Alt som lagres i leaderboard er permanent, men du kan slette leaderboard.db og restarte flask for å wipe all data i filen

## Laget med
- [Godot 4](https://godotengine.org/)
- [Flask](https://flask.palletsprojects.com/)
- SQLite
